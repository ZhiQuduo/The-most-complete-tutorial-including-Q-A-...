# 双相机浏览器预览

当前用户确认：腕部 `/dev/video0`，旁侧 `/dev/video2`。重新插拔或重启后仍需核对设备身份。

当前 OpenCV 报错说明 `imshow` / `destroyAllWindows` 的 GUI 后端不可用。它不代表摄像头无法采集，也不需要因此重新编译 OpenCV。本脚本使用现有 OpenCV 采集和 JPEG 编码，使用 Python 标准库提供本机浏览器预览，不调用 HighGUI、不导入机器人或写电机。

## 放入 Ubuntu

将本文件夹的 `preview_web.py` 复制到 Ubuntu 的 `/home/user/lerobot/preview_web.py`。

也可以在 Windows/Codex 中打开脚本，全选复制；Ubuntu 终端执行 `nano ~/lerobot/preview_web.py`，用 `Ctrl+Shift+V` 粘贴，然后 `Ctrl+O`、回车保存，`Ctrl+X` 退出。

## 运行

先退出其他相机预览或录制程序，避免设备被占用。Ubuntu 终端：

```bash
conda activate so101
cd ~/lerobot
python preview_web.py
```

在 **Ubuntu 内的 Firefox** 地址栏打开：

```text
http://127.0.0.1:8765
```

不要在 Windows 的浏览器使用这个 localhost 地址；服务运行在 Ubuntu 内，并只监听 Ubuntu 的回环地址。

终端应分别显示 `wrist 已读到画面` 和 `side 已读到画面`。打印的 640×480、15 FPS 是驱动返回的流配置，不是实际测得的采集帧率；网页刷新频率也不等于相机帧率。

取景检查：腕部能看到夹爪与抓取区域；旁侧覆盖 A、B 和夹爪的主要运动区。页面显示最近刷新时间；两秒没有新采集帧时不再发送旧帧，页面提示查看终端。

## 退出

在运行预览的终端按 `Ctrl+C`，等待退出。**开始 LeRobot 带相机遥操作或录制前，先退出本预览程序**，释放两台相机。

若 8765 端口被占用，可以运行 `python preview_web.py --port 8766`，在 Ubuntu 浏览器打开 `http://127.0.0.1:8766`。

无需重装或混装 `opencv-python` 和 `opencv-python-headless`。官方包说明指出这些包共用 `cv2` 命名空间，应只选择一种；headless 包不包含 GUI 功能。

参考：[OpenCV 官方 Python 包说明](https://pypi.org/project/opencv-python-headless/)、[Python HTTP 服务接口](https://docs.python.org/3/library/http.server.html)。

脚本已做语法和命令帮助检查，双相机实机画面仍需由你运行验证；此前输出只确认两台设备打开并返回参数，未确认双路连续取帧成功。
