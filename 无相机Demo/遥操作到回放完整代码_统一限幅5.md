# 从遥操作到新轨迹录制、归位、回放的完整代码

整理日期：2026-10-15。适用于本机已安装的 LeRobot 0.6.2、Ubuntu 的 `so101` 环境和已验证能归位的 `~/lerobot/so101_home.py`。

录制和回放统一使用 `max_relative_target=5`。这是排查此前滞后时的待验证配置，不代表误差已经解决。旧 Python 脚本的 `demo` 子命令仍固定使用 2，本文使用 Bash 函数直接调用官方回放，因此不需要修改 Python 脚本。

**全部命令在 Ubuntu 的同一个终端分段执行，每步成功后再继续。不要一次粘贴整份说明。变量和函数只在这个终端有效。**

## 1. 激活环境、确认设备

将两块控制板 USB 都连接给 Ubuntu，使用已经核对的对应电源，固定底座。

```bash
conda activate so101
cd ~/lerobot
python -m serial.tools.list_ports -v
```

本次会话原先确认 F=`/dev/ttyACM0`、L=`/dev/ttyACM1`。如果没有重新插拔且设备未变，可沿用；重启、重新插拔后应运行 `lerobot-find-port`，按提示只拔一块已知角色的 USB，按回车识别，再接回 Ubuntu。两臂分别确认。

本次已经确认的端口直接填好如下，无需手动输入。仅适用于本次连接未改变的设备；重启或重新插拔后仍需重新核对：

```bash
F_PORT=/dev/ttyACM0
L_PORT=/dev/ttyACM1
```

读取端口后先核对，再授权：

```bash
printf 'F 从臂=%s\nL 主臂=%s\n' "$F_PORT" "$L_PORT"
sudo chmod 666 "$F_PORT" "$L_PORT"
python so101_home.py --help
```

环境必须是 `(so101)`，两个端口必须不同。若任何命令报错，先停止处理，不继续执行运动命令。

## 2. 先做普通遥操作，选好起始姿态

让两臂处于相近姿态，夹爪为空，手退出从臂运动区后运行：

```bash
lerobot-teleoperate \
  --robot.type=so101_follower \
  --robot.port="$F_PORT" \
  --robot.id=follower_arm \
  --robot.max_relative_target=5 \
  --robot.disable_torque_on_disconnect=false \
  --teleop.type=so101_leader \
  --teleop.port="$L_PORT" \
  --teleop.id=leader_arm \
  --fps=30
```

提示复用校准时，确认角色和最终正确校准文件后按回车。缓慢试动，选一个夹爪空载、关节不过度伸展、周围有空间的起始姿态。停住主臂，等待从臂稳定约 2 秒，再按 `Ctrl+C` 正常退出。

这次 F 从臂退出后保持上力；不要强掰它。L、F 的姿态与夹爪状态保持不变，准备录制。

## 3. 为这一次新录制生成名称

每次新录制只执行一次下面这段。录制、保存起点、回放期间不要重新生成名称：

```bash
DEMO_NAME="so101_pick_place_$(date +%Y%m%d_%H%M%S)"
DEMO_REPO="local/$DEMO_NAME"
DEMO_ROOT="$HOME/lerobot/recordings/$DEMO_NAME"
DEMO_POSE="$HOME/lerobot/poses/${DEMO_NAME}_start.json"
printf '本次名称：%s\n数据目录：%s\n起点文件：%s\n' "$DEMO_NAME" "$DEMO_ROOT" "$DEMO_POSE"
```

名称包含时间，原有轨迹保留。记下终端打印的实际路径，方便以后再次使用。

## 4. 遥操作并录制一次

把物块放在 A，B 保持空，确认两臂初始姿态没有因整理桌面而变化，然后运行：

```bash
lerobot-record \
  --robot.type=so101_follower \
  --robot.port="$F_PORT" \
  --robot.id=follower_arm \
  --robot.max_relative_target=5 \
  --robot.disable_torque_on_disconnect=false \
  --teleop.type=so101_leader \
  --teleop.port="$L_PORT" \
  --teleop.id=leader_arm \
  --dataset.repo_id="$DEMO_REPO" \
  --dataset.root="$DEMO_ROOT" \
  --dataset.single_task="Move the foam block from A to B" \
  --dataset.fps=30 \
  --dataset.num_episodes=1 \
  --dataset.episode_time_s=60 \
  --dataset.reset_time_s=0 \
  --dataset.video=false \
  --dataset.push_to_hub=false \
  --dataset.no_stamp=true \
  --display_data=false \
  --play_sounds=false
```

看到 `Recording episode 0` 后，前 3～5 秒保持稳定，然后慢慢完成一次搬运。夹住后停 1～2 秒再抬起；物块接近放置位置并稳定后再松开。动作完成后停稳，等待 60 秒自动保存、退出。异常动作立即停止；正常保存不要用 `Ctrl+C` 提前结束当前段。

录制期间依然由你控制 L。F 在正常退出后保持上力。若目录已存在或命令失败，不要删除旧数据或继续回放。

## 5. 保存新轨迹的起点，只读检查

```bash
python so101_home.py save-start \
  --port "$F_PORT" \
  --dataset "$DEMO_ROOT" \
  --repo-id "$DEMO_REPO" \
  --pose "$DEMO_POSE"
```

看到“起点已保存”后执行：

```bash
python so101_home.py check \
  --port "$F_PORT" \
  --pose "$DEMO_POSE"
```

这两步不驱动电机。起点取自本次新轨迹第 0 帧的从臂实际位置，不使用旧轨迹起点。`save-start` 的零差值表只是起点与自身比较，`check` 表格才是当前反馈。

## 6. 第一次空载归位

拿走物块，确认夹爪为空，整条返回路径没有桌面、线缆或其他物体阻挡。运行：

```bash
python so101_home.py home \
  --port "$F_PORT" \
  --pose "$DEMO_POSE" \
  --execute
```

倒计时后缓慢归位。必须确认新路径归位顺利，才能继续。该脚本是关节插值，不具备自动避障。

## 7. 定义一次“归位→回放→归位”命令

下面这段仅定义函数，不会立即驱动：

```bash
replay_once() {
  python so101_home.py home \
    --port "$F_PORT" \
    --pose "$DEMO_POSE" \
    --execute || return

  lerobot-replay \
    --robot.type=so101_follower \
    --robot.port="$F_PORT" \
    --robot.id=follower_arm \
    --robot.max_relative_target=5 \
    --robot.disable_torque_on_disconnect=false \
    --dataset.repo_id="$DEMO_REPO" \
    --dataset.root="$DEMO_ROOT" \
    --dataset.episode=0 \
    --play_sounds=false || return

  python so101_home.py home \
    --port "$F_PORT" \
    --pose "$DEMO_POSE" \
    --execute
}
```

任一步失败或被中断，函数会停止，不会自动执行后面的动作。它调用官方回放并明确传入限幅 5；不用旧脚本中固定限幅 2 的 `demo` 命令。

## 8. 先空载回放，再带物块

继续不放物块，执行一次：

```bash
replay_once
```

从臂自行归位、回放、返回起点，L 不用操作。观察之前的滞后、幅度不足是否改善，不应因统一限幅就提前认为准确度已经达标。

整套空载动作顺利后，将物块放回录制时 A 的位置和朝向，清空 B，手退出运动区，再执行：

```bash
replay_once
```

每次运行只演示一遍，不无限循环。发现物块没放下、卡住、关节受阻或异常声音时立即停止。异常运动时立即切断 F 电机电源；`Ctrl+C` 不是硬件急停。

## 9. 结束使用时卸力

录制、归位和回放后 F 可能仍保持上力。先支撑前臂，再运行：

```bash
python so101_home.py release \
  --port "$F_PORT" \
  --pose "$DEMO_POSE" \
  --execute
```

确认卸力后断开 F 电源，正常关闭 Ubuntu。不要无人照看地长时间保持上力。

如果在生成起点前中途退出，不能用尚未生成的起点文件卸力；先支撑从臂再断开对应电机电源即可。

## 以后重新打开终端，回放这次轨迹

重新激活环境、确认当前 F 端口和权限。把下方中文占位替换为第 3 步记下的实际名称，不能直接复制占位文字运行：

```bash
DEMO_NAME="替换为当时打印的完整名称"
DEMO_REPO="local/$DEMO_NAME"
DEMO_ROOT="$HOME/lerobot/recordings/$DEMO_NAME"
DEMO_POSE="$HOME/lerobot/poses/${DEMO_NAME}_start.json"
```

重新填写本次 `F_PORT`，再复制第 7 步定义函数，然后按第 8 步先空载运行。已有轨迹不需要重新录制或重新保存起点。

参考：[LeRobot 官方遥操作、录制与回放教程](https://huggingface.co/docs/lerobot/en/il_robots)。参数以此前本机字段检查为基础；本流程未替你执行任何实际运动。无相机回放不修正物块移动、底座偏移、夹爪滑移或机械回差。
