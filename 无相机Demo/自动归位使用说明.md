# SO101：固定起点、自动归位与轨迹回放

适用：当前 `so101` 环境、`follower_arm` 校准，以及已经成功空载回放的 `so101_pick_place_01`。

本工具保存在 Windows 的 `D:\具身智能\无相机Demo`。所有 Python 命令必须在 **Ubuntu 虚拟机的 so101 环境**执行。

## 能做什么

- `save-start`：从现有录制的第 0 帧提取从臂**实际位置**，保存为固定起点，不需要重新录制。
- `save-current`：另存一个当前实际姿态，适用于以后重新设计演示；它不会让旧轨迹自动适配新起点。
- `check`：读取当前位置，显示与起点的差值，不驱动电机。
- `home --execute`：缓慢回到保存的起点，检查反馈是否到位。
- `demo --execute`：归位 → 调用已验证的官方轨迹回放 → 正常完成后归位。
- `release --execute`：支撑从臂后，主动卸力。

自动归位能减少每次开始时的关节姿态差异；它不等于提高机械臂本体精度。物块位置、底座固定、夹爪接触、回差及校准都会影响最终搬运结果。没有相机时，物块移动后不会被自动识别。

## 1. 将脚本放进 Ubuntu

仅需复制 `so101_home.py`，测试文件不需要传进 Ubuntu。

如果已经能通过共享文件夹或文件复制传输，把它放到：

```text
/home/user/lerobot/so101_home.py
```

如果暂时没有共享文件夹：

1. 在 Windows/Codex 中打开 `so101_home.py`，全选、复制文件正文。
2. Ubuntu 终端执行 `nano ~/lerobot/so101_home.py`。
3. 在 nano 中用 `Ctrl+Shift+V` 粘贴全部代码。
4. 按 `Ctrl+O`，回车保存，再按 `Ctrl+X` 退出。

进入环境并检查文件是否完整：

```bash
conda activate so101
cd ~/lerobot
python so101_home.py --help
```

应显示 `save-start`、`save-current`、`check`、`home`、`demo`、`release` 等命令。

## 2. 确认端口与设备状态

先退出其他遥操作/回放程序，不要同时运行两个占用同一串口的进程。两块 USB 仍交给 Ubuntu；从臂使用已经核对的 12V 电源。

2026-10-15 本次识别结果是 F=`/dev/ttyACM0`、L=`/dev/ttyACM1`。**如果重启或重新插拔过 USB，先重新识别，不要沿用旧编号。**

下面以本次 F=`/dev/ttyACM0` 为例，端口改变时替换所有命令中的路径：

```bash
sudo chmod 666 /dev/ttyACM0
```

脚本还会检查保存时的控制板 USB 序列号、六个电机型号与校准参数。校准不一致时会停止，不会自行覆盖校准。

## 3. 保存这段轨迹的起点（第一次执行）

```bash
python so101_home.py save-start --port /dev/ttyACM0
```

该命令读取原录制数据和电机信息，不发送位置目标、不改变力矩。默认数据目录是：

```text
/home/user/lerobot/recordings/so101_pick_place_01
```

完整精度的起点、控制板序列号与校准文件摘要将保存到：

```text
/home/user/lerobot/poses/demo_start.json
```

你截图里的起点近似值如下，实际保存使用原始数据的完整数值，不使用此表的四舍五入值：

| 关节 | 起始实际值 | 单位 |
| --- | ---: | --- |
| shoulder_pan | -4.92 | 度 |
| shoulder_lift | -73.14 | 度 |
| elbow_flex | 92.75 | 度 |
| wrist_flex | 36.62 | 度 |
| wrist_roll | -3.12 | 度 |
| gripper | 3.26 | 校准范围百分比 |

起点文件已存在时脚本不会覆盖。如需另存一个配置，使用不同文件名，例如 `--pose "$HOME/lerobot/poses/demo_start_v2.json"`；后续命令要使用同一路径。

## 4. 只读检查

```bash
python so101_home.py check --port /dev/ttyACM0
```

终端会显示当前六关节位置、起点、差值和归位预计时间。这一步不驱动电机。

校准变更、控制板不同、反馈超出校准范围、模式/状态异常时，脚本会停止。不要直接改 JSON 来绕过检查。

## 5. 第一次空载归位

先拿走物块，确保夹爪空载、底座固定，**整条归位路径**没有桌面、线缆或其他物体阻挡。脚本采用关节位置插值，不能自动避障；回放路径顺利不代表这条返回路径也已验证。

```bash
python so101_home.py home --port /dev/ttyACM0 --execute
```

程序显示位置后倒计时 3 秒，然后开始缓慢归位：

- 前五轴目标速度约不超过 5 度/秒，夹爪约不超过 10 个百分点/秒；量化和真实伺服动态不等于理想模型。
- 先把旧目标覆盖为当前反馈，再启动力矩，避免直接追逐遗留目标。
- 跟随误差大时暂停推进，持续跟不上、反馈异常或超时会中止。
- 单轴跨度超过 90 度时不直接执行，请先用已验证的遥操作分段靠近起点。
- 反馈误差需在前五轴 1 度、夹爪 2 个百分点以内，连续稳定 0.5 秒，才显示归位完成。这是编码器关节反馈阈值，不是末端毫米精度承诺。

**归位完成后电机继续保持上力。不要徒手掰关节。**

归位阶段中断或错误时，程序会尝试停在当前反馈位置并保持上力；通信故障时不能保证这条停止目标送达。官方回放阶段沿用其退出行为，电机可能继续保持最后一次目标，不会自动返回。出现异常运动，应立即切断 F 电机电源。`Ctrl+C` 不是硬件急停。

## 6. 一条命令完成演示并自动归位

只有第 5 步的返回路径已空载确认顺利，才继续。第一次仍拿走物块，验证整套流程：

```bash
python so101_home.py demo --port /dev/ttyACM0 --execute
```

流程：**缓慢归位 → 原轨迹回放 → 缓慢归位 → 保持起点上力**。

回放阶段与录制统一使用目标限幅 `5`，不改变原数据或帧率。2026-10-15 用户反馈限幅 `2` 时明显滞后/幅度不足，改为 `5` 后可以正常完成，因此脚本回放默认值已改为 `5`。缓慢归位仍使用原有速度和独立反馈限幅，不应将归位参数里的 `2` 一并替换。

官方回放通过 `disable_torque_on_disconnect=false` 保留结束时上力，避免程序交接时主动卸力；其连接初始化仍可能短暂切换力矩，不能把软件交接视为绝对无位移。

回放异常或被中断时，不会继续自动返回。一次演示结束后不会无限循环，避免在你重新摆放物块时启动下一次。

整套空载确认后，把物块放回 A。重复同一条命令即可演示，每次都从保存的起点开始，并在结束后返回。观察物块已放下、夹爪为空；掉落、卡住或仍夹着物体时应停止。

## 7. 结束使用：支撑好再卸力

先扶稳从臂，再执行：

```bash
python so101_home.py release --port /dev/ttyACM0 --execute
```

确认卸力后断开 F 电源，再正常关闭虚拟机。脚本正常归位后保持上力，不宜无人照看地长时间通电。

## 以后想保存一个新的姿态

使用原遥操作把从臂放到合适位置，退出后稳定支撑，再另存：

```bash
python so101_home.py save-current \
  --port /dev/ttyACM0 \
  --pose "$HOME/lerobot/poses/new_start.json"
```

它只适合作为新的归位点。旧轨迹不会自动平移或适配这个起点；需要从新姿态重新录制，再用 `save-start` 绑定新轨迹。
