证据标签：

- **已验证**：有当前文件、测试、数据审计或日志支撑。
- **用户观察**：来自操作者现场观察，但未必有独立视频/统计复核。
- **软件验证**：只证明代码、协议或离线数据有效，不证明实机任务完成。
- **待验证**：需要新的实机试验或发布前处理。
