## 1. 仍未彻底消除的模型问题

训练动作中 `shoulder_lift` 最小值约为 -107.253°，而当前硬件校准下界约为 -104.879°。模型因此经常预测比当前硬件范围更低的值。运行时 5°投影可以让指令保持在硬件边界内，但这只是部署保护，不是“模型已经学会边界”。

下一版更好的处理方式：

1. 录制前统一校准和真实可达边界。
2. 检查数据里的 action 是期望目标还是经过限制后的实际安全目标。
3. 清理/裁剪超出现役硬件边界的标签并重新训练。
4. 报告投影比例；如果大量动作都被投影，不应只继续放大阈值。

## 2. 排查顺序

ACT 异常时按以下顺序，不先改模型或一口气放宽所有阈值：

1. 只拍 front/wrist 当前画面，与训练起点对比。
2. 检查 Follower 当前姿态、空夹爪和物块位置。
3. 检查 Windows `/health` 的 checkpoint、CUDA、协议和 `motion_enabled=false`。
4. 审计本次 telemetry：是网络、预测边界、模型/反馈差还是持续跟踪滞后。
5. 比较请求目标、发送目标和实际反馈，定位到具体关节/方向。
6. 只修改有证据的最小参数，并从 5 秒 commissioning 重新验证。
