## 3. 已实现的具体产物

`D:\具身智能\README.md` 包含：

1. 标明所有运行代码在 Ubuntu 执行，Windows 项目目录与 Ubuntu `~/lerobot` 不是同一个文件系统路径。
2. 每次新开终端激活 Conda、进入项目，建议检查依赖并枚举串口。
3. VMware 菜单路径：虚拟机 → 可移动设备 → USB 串口设备 → 连接（断开与主机连接）；两块控制板分别处理。
4. 用逐板 USB 断开/接回识别主从角色；重连后重新枚举，不能永久绑定 ACM 编号。
5. 以变量构造 `lerobot-teleoperate` 基础命令；`--robot.type=so101_follower`、`--teleop.type=so101_leader`；端口及校准名称均需填写。
6. 明确 `--robot.id`/`--teleop.id` 是校准文件的设备名称，不是总线舵机 ID 1–6；保留成功命令里的自定义 calibration_dir、相机等参数。
7. 针对 Conda 未加载提供已有 miniconda3/anaconda3 的 `conda.sh` 加载分支；不是重新安装流程。
8. 针对权限不足提供设备组检查与条件性的 `sudo usermod -aG dialout "$USER"`；注销重登/重启后生效。
9. 用 `sys.executable`、`pwd`、`command -v lerobot-teleoperate` 诊断错误环境或路径。
10. 区分每次启动、一次性配置和仅故障时执行；日常启动无需重新 setup motors 或无条件重校准。
