# 03 代码与运行入口

- `无相机Demo/inspect_trajectory.py`：轨迹结构/帧数检查。

- `无相机Demo/遥操作到回放完整代码_统一限幅5.md`：流程说明。
- `SO101遥操作说明_虚拟机重启后.md`：日常启动和端口复核手册。

## Ubuntu 遥操作模板

在每次重启/重插后替换实际端口和既有校准 ID：

```bash
conda activate so101
cd ~/lerobot
python -m pip check
python -m serial.tools.list_ports -v
lerobot-teleoperate \
  --robot.type=so101_follower --robot.port=/dev/ttyACM0 --robot.id=follower_arm \
  --teleop.type=so101_leader --teleop.port=/dev/ttyACM1 --teleop.id=leader_arm \
  --fps=30
```

上面的端口只是模板；若角色反了，先停下并按单板拔插法重新映射。诊断脚本 `/tmp/diagnose_f3.py` 属于临时工具，终端重启后通常需要重新创建；`=python` 不能出现在命令开头。

## 回放限幅语义

`max_relative_target` 限制单个控制更新相对目标的幅度，具体物理单位由 LeRobot 控制实现决定。它不是速度上限、轨迹精度保证或安全认证。当前 Windows 脚本官方回放调用为 5；Ubuntu 副本是否相同必须现场 `rg "max_relative_target" ~/lerobot` 或查看实际命令后确认。

## 自动归位安全条件

归位前从臂供电正常、机械路径空闲、起点校验通过；归位时保持观察。跨度超过脚本 90° 防护时应先用已验证遥操作分段靠近，不要删除该防护。异常时切断 Follower 电源。
