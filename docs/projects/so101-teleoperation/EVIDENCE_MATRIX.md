## 证据优先级

1. 当前现场的新鲜日志、设备枚举和用户明确动作结果。
2. 带时间戳的历史原始日志/会话导出。
3. 脚本测试、静态检查和文件存在性。
4. 设计说明、计划和推断。

发生冲突时，保留所有记录，优先最新且可复现的原始证据；不要覆盖旧文件。
