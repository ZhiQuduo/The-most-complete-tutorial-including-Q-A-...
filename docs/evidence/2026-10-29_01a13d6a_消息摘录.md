在 **Ubuntu 的 `(so101)` 终端**，整段复制执行：

```bash

mkdir -p "$HOME/lerobot_demos"

lerobot-record \
  --robot.type=so101_follower \
  --robot.port=/dev/ttyACM0 \
  --robot.id=follower_arm \
  --robot.max_relative_target=5 \
  --robot.cameras='{}' \
  --teleop.type=so101_leader \
  --teleop.port=/dev/ttyACM1 \
  --teleop.id=leader_arm \
  --dataset.repo_id="local/$DEMO_NAME" \
  --dataset.root="$DEMO_ROOT" \
  --dataset.single_task="Small gripper movement without cameras" \
  --dataset.fps=30 \
  --dataset.episode_time_s=5 \
  --dataset.reset_time_s=0 \
  --dataset.num_episodes=1 \
  --dataset.video=false \
  --dataset.push_to_hub=false \
  --dataset.no_stamp=true \
  --display_data=false \
  --play_sounds=false
```

这里将相机配置设为空，只保存关节观测与动作数据；数据保存在本地，关闭上传。[官方配置说明](https://github.com/huggingface/lerobot/blob/main/src/lerobot/configs/dataset.py)
