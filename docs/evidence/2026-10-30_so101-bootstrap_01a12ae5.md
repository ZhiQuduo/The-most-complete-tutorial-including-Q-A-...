3. **在 Windows 上准备独立的软件环境**

   以下命令在 **Miniforge Prompt** 中逐行运行。某一行报错就停下来处理：

   ```bat
   conda create -y -n so101 python=3.12
   conda activate so101
   conda install -y ffmpeg -c conda-forge

   mkdir D:\so101_work
   cd /d D:\so101_work

   cd lerobot
   python -m pip install -e ".[core_scripts,feetech]"
   ```

   这里沿用 Seeed 的仓库，并根据当前依赖补上 `core_scripts`，用于校准、遥操作和录制。[LeRobot 安装说明](https://huggingface.co/docs/lerobot/installation)、[Seeed 当前依赖配置](https://github.com/Seeed-Projects/lerobot/blob/main/pyproject.toml)

   安装后检查：

   ```bat
   python --version
   python -m pip check
   lerobot-calibrate --help
   lerobot-teleoperate --help
   ```

   **通过标准：** Python 显示 3.12，依赖检查没有冲突，两个工具能显示帮助信息。以后每次打开新窗口，先运行：

   ```bat
   conda activate so101
   ```

4. **识别两块驱动板的 COM 端口**

   先用 USB 数据线连接一块驱动板，在 Windows 的“设备管理器 → 端口（COM 和 LPT）”查看新增端口，再换另一块板确认。

   也可以运行：

   ```bat
   python -m serial.tools.list_ports
   ```

   给两块板记好端口，例如：

   ```text
   从臂驱动板：COM5
   主臂驱动板：COM6
   ```

   **下面所有 COM5、COM6 都是示例，必须替换成你的实际端口。** 重新插拔后可能变化，不能只凭插入顺序判断。

   如果没有出现端口，先检查 USB 线是否支持数据传输，再根据驱动板的 USB 转串口芯片确认驱动。

5. **先逐个配置舵机，再组装机械臂**

   这一步给舵机设置通信编号和波特率，与后面的“整臂校准”是两件事。

   **配置从臂时，驱动板接 12V，且一次只连接一个舵机。**

   假设从臂板是 COM5：

   ```bat
   lerobot-setup-motors --robot.type=so101_follower --robot.port=COM5
   ```

   按终端提示依次接入对应电机。程序通常从夹爪开始，编号顺序为：

   ```text
   6 夹爪 → 5 手腕旋转 → 4 手腕弯曲
   → 3 肘部 → 2 肩部 → 1 底座
   ```

   每次更换电机时：

   - 先断开舵机电源。
   - 接好程序要求的电机，确认它没有串接其他电机。
   - 恢复正确电源，再按回车。
   - 确认程序报告设置成功，再进行下一个。

   主臂同样操作，但改用 **5V 电源**和主臂端口：

   ```bat
   lerobot-setup-motors --teleop.type=so101_leader --teleop.port=COM6
   ```

   **通过标准：** 两条臂的 12 个电机都完成设置，没有漏号或通信报错。[官方舵机设置流程](https://huggingface.co/docs/lerobot/so101#set-the-motors-ids-and-baudrates)

   完成后，按原网页的组装图片或视频，从底座向上安装。对照每张图检查电机方向、舵盘位置和线缆走向，尤其注意主臂手柄与从臂夹爪的区别。

   最后串接电机：

   ```text
   驱动板 → 1号 → 2号 → 3号 → 4号 → 5号 → 6号
   ```

   不要仅凭“外形装得像”就上电，线缆也需要留出关节活动余量。[Seeed 组装图与视频](https://wiki.seeedstudio.com/cn/lerobot_so100m_new/#校准舵机并组装机械臂)

6. **固定机械臂，然后分别做整臂校准**

   先用夹具固定底座，清空从臂运动范围。断电开关应放在伸手可及、无需进入运动范围的位置。首次运行按教程要求清空周围约 1 米空间；异常运动、抖动或异响时立即停止并断电。[Seeed 运行安全说明](https://wiki.seeedstudio.com/cn/lerobot_so100m_new/)

   从臂校准：

   ```bat
   lerobot-calibrate --robot.type=so101_follower --robot.port=COM5 --robot.id=follower_01
   ```

   主臂校准：

   ```bat
   lerobot-calibrate --teleop.type=so101_leader --teleop.port=COM6 --teleop.id=leader_01
   ```

   根据终端提示，先将关节放在活动范围中间附近，再记录各关节运动范围。**只有在校准程序已释放电机扭矩、明确要求手动移动时才移动关节；遇到阻力不要硬掰，也不要拉扯线缆。**

   后续始终使用 `follower_01` 和 `leader_01`，让程序使用同一套校准文件。[官方整臂校准说明](https://huggingface.co/docs/lerobot/so101#calibrate)

7. **做第一次主从跟随**

   校准成功后，先不接摄像头，运行：

   ```bat
   lerobot-teleoperate --robot.type=so101_follower --robot.port=COM5 --robot.id=follower_01 --teleop.type=so101_leader --teleop.port=COM6 --teleop.id=leader_01
   ```

   启动前将两条臂放在相近、不会碰桌面的姿态。先用小幅度、缓慢动作检查各关节和夹爪，再逐渐增加活动范围。

   我建议你用以下现象判断这一阶段完成：

   - 从臂动作与主臂对应。
   - 没有突然跳动、持续抖动或碰撞。
   - 线缆没有被拉紧。
   - 能连续操作几分钟。

   正常结束用 `Ctrl+C`；出现失控迹象直接断电，不能把软件退出当作硬件急停。[官方遥操作说明](https://huggingface.co/docs/lerobot/il_robots#teleoperate)

8. **跟随稳定后，再接相机、录数据、训练**

   **接相机：** 先用一个固定的 USB 摄像头，画面能完整看到物体、夹爪和放置区域。查找编号：

   ```bat
   lerobot-find-cameras opencv
   ```

   摄像头编号可能在重新插拔后变化，要看实际输出。[官方相机说明](https://huggingface.co/docs/lerobot/cameras#find-your-camera)

   **录数据：** 我建议第一个任务选“把小方块放进盒子”。先录 5 次，检查画面和动作是否正确保存。这里的一次完整任务叫一个 **episode**。流程确认后再增加成功示范，并逐渐改变物体起始位置；初次录制可用 `--dataset.push_to_hub=false` 保存在本地。[官方数据采集说明](https://huggingface.co/docs/lerobot/il_robots#record-a-dataset)

   **训练：** 第一个模型建议用 ACT。它通过你的示范学习动作；摄像头正常、数据质量合格后，再根据电脑显卡配置训练环境。[ACT 官方介绍](https://huggingface.co/docs/lerobot/act)

   **真实运行：** 训练后在清空、固定好的工作台上测试，记录成功次数和失败原因。训练完成本身不能说明机械臂已经学会任务。

**你现在先做第 1、2 步：清点零件、标记 5V/12V 电源、按减速比分出 L1～L6 和 F1～F6。** 然后安装软件，完成单个舵机配置后再开始装臂。这样后面发现通信或编号问题时，最容易排查。
