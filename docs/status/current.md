## 当前固定设计决策

- Ubuntu 独占相机、串口与运动；Windows 只推理。
- 双相机键固定为 `observation.images.front` 和 `observation.images.wrist`。
- ACT 原生 `chunk_size=30`、执行 `n_action_steps=10`；不再改为 5。
- 自动归位继续使用已接受的 5°粗归位方案；不放宽 15°粗接管入口。
- ID3 `elbow_flex` P=32；I/D、Lock 和力矩限制不增加。
- 夹爪闭合接触允许 5%持续差；张开仍 2%；前五轴持续滞后仍 5°。
- extended profile 最长 300 秒，但必须从 5 秒 commissioning 逐级验证。
