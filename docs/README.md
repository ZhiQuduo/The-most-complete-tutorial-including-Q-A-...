## 后续存放规则

1. 每次完整交接放到 `交接/YYYY-MM-DD_主题/`，文件名前两位表示阅读顺序。目录日期是整理日期，不伪装成实验日期。
2. 每批至少包含接手摘要、环境、历史、证据、未完成项；机器可读证据放 `evidence/`，图片放 `assets/`。
3. 新增交接后更新本页与交接索引的“当前入口”。旧批次保留作历史，不覆盖旧实测结果。
4. 实验写清日期、来源、命令、输入、输出、通过标准、失败和局限；区分软件测试、用户设备日志、推断、未验证计划。
5. 不复制权重、虚拟环境、VM 磁盘或整个会话原始流到文档目录。会话摘录只保存用户及对外答复，不保存内部推理、系统/开发者消息或凭据。
6. 不因整理文档移动代码、校准、轨迹或模型。路径变更必须另行执行和核验。
7. 历史文档中的 IP、PID、串口和视频编号是快照，运行前重新核对；新文档优先表达最新证据，仍需保留矛盾来源。
